# First boot and login credentials

Nexbox boots into a graphical login screen (LightDM) with the Nexbox maze background, the Nexzer wordmark, and the tagline *Nexbox OS, Offensive Edition*.

## Default live credentials

| Field | Value |
|---|---|
| Username | `nexbox` |
| Password | `nexbox` |

## After install to disk

The installer asks you to create your own user account during installation. The default `nexbox` user does not exist on an installed system unless you chose that username during install.

## Change the live password

```bash
passwd
```
