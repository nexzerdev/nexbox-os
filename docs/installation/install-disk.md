# Install Nexbox to disk

## From the live desktop (easiest)

1. Boot Nexbox in live mode.
2. Log in (`nexbox` / `nexbox`).
3. Double-click the **Install Nexbox** launcher on the desktop.
4. Follow the graphical installer.

## From the boot menu

When the Nexbox boot menu appears, instead of choosing **Live Nexbox**, choose:

- **Graphical install**: step-by-step installer with a GUI
- **Install**: text-based installer

## Dual-boot with Windows

:::warning
**Back up important data first.** Partitioning mistakes are not reversible.
:::

- Shrink your Windows partition from inside Windows first using Disk Management. Do not shrink NTFS from Linux.
- Boot the Nexbox installer.
- Use **Manual** or **Side by side** partitioning to keep your Windows partition.
